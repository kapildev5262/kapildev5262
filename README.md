### 🤫 High-Speed Solana Trading Bot *(Production — Calibraint)*
> Rust trading infrastructure for Solana DEXes. Jito bundle submission for MEV-optimised execution. Yellowstone gRPC price-feed streaming. Real-time pump detection across Raydium, Jupiter, Orca, Phoenix. Multi-RPC failover with Prometheus instrumentation.  
> **Stack:** `Rust` `Tokio` `Jito SDK` `Yellowstone gRPC` `Chainstack` `Bitquery`  
> ⚠️ *Client NDA — code private, happy to discuss architecture*

---

### 🟡 [`yellowstone-grpc-solana-rust`](https://github.com/kapildev5262/yellowstone-grpc-solana-rust)
> Production-ready Rust template for Yellowstone gRPC — account subscriptions, transaction filtering, auto-reconnect, ping-keepalive, multi-provider failover. The clean starter kit I wished existed when I started.  
> **Stack:** `Rust` `Tonic` `Prost` `Tokio` `Yellowstone gRPC`

---

### 🌉 [`Base-ICP Bridge with Chain Fusion`](https://github.com/kapildev5262/Base-ICP-Bridge-with-Chain-Fusion)
> Cross-chain token bridge: Base (Ethereum L2) ↔ ICP. Motoko canisters handle ICP side; Solidity + multi-sig for Base; Node.js validator monitors events on both chains.  
> **Stack:** `Motoko` `Solidity` `Hardhat` `Node.js` `ICP SDK` `Ethers.js`

---

### 🔷 [`Aptos Token Creator & DEX`](https://github.com/kapildev5262/aptos-coin-creator)
> End-to-end dApp: Move module compilation → liquidity pool on Liquidswap → token swap. React multi-step workflow. One fork from the community.  
> **Stack:** `Move` `Aptos SDK` `React.js` `Petra Wallet` `Liquidswap`

---

### ⭐ [`Stellar Cross-Border Payments`](https://github.com/kapildev5262/Private-Stellar-Cross-Border-Solution)
